    subgraph GeneralPrinciple [通用原理：栈帧展开 (Stack Unwinding)]
        A[函数 A] -->|调用| B[函数 B]
        B -->|调用| C[函数 C]
        C -->|产生异常| D{当前方法是否有 catch?}
        D -- 无 -->|弹出栈帧并回溯| E[回溯至函数 B]
        E -->|查找处理器| F{函数 B 是否有 catch?}
        F -- 无 -->|继续回溯| G[回溯至函数 A]
        G -->|查找处理器| H{函数 A 是否有 catch?}
        H -- 有 --> I[执行 catch 逻辑]
        H -- 无 --> J[抛给 Runtime 或 打印 Uncaught Error]
    end

    subgraph LanguageSpecific [各语言实现特性]
        Java[<b>Java (JVM)</b><br/>通过 fillInStackTrace 捕获快照<br/>性能损耗较高]
        Cpp[<b>C++ (Native)</b><br/>依赖 DWARF 调试信息表<br/>Zero-cost 异常处理方案]
        JS[<b>JS (V8)</b><br/>Error.stack 属性<br/>通过 Error.prepareStackTrace 自定义]
        Cangjie[<b>Cangjie</b><br/>Exception 基类持有 StackTrace<br/>原生支持回溯信息打印]
    end
